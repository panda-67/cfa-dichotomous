Untuk data biner (0/1) dengan n = 108, kegagalan model bukan error analisis, tetapi batas matematis:

1. Varians rendah

Data biner hanya punya dua nilai → varian kecil → matriks korelasi menjadi sparse dan tidak stabil.

2. Korelasi antar-item terlalu tinggi

Biner + sampel kecil → korelasi polikorik sering “meledak” atau menjadi singular → FA/CFA tidak konvergen.

3. Dimensi terlalu banyak untuk ukuran sampel

Estimator dengan “PD = TRUE” (positive-definite) butuh matriks korelasi yang stabil, sementara 108 sampel tidak cukup untuk banyak parameter.

4. Homogenitas loading

Item biner cenderung memuat mirip sehingga struktur faktor menjadi tidak teridentifikasi (underidentified).

5. Estimasi polikorik → tidak robust di n kecil

Polikorik memerlukan cukup observasi di semua sel kontingensi; dengan biner + n kecil, banyak sel kosong.
